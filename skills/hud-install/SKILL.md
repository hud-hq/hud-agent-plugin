# Install the Hud SDK

The install steps live at skills.hud.io and change independently of this plugin. Always use the current version; never install Hud from memory.

1. Fetch https://skills.hud.io/install/skill/install-hud-sdk/SKILL.md and follow it. It routes to language-specific skills under the same base URL; fetch those as it says. If your sandbox blocks network access, ask the user to approve it.
2. If you still can't fetch it, tell the user and send them to https://skills.hud.io/install. Don't improvise an install.
